# 화성 분석 스트레스 테스트 v0.2

대표 문제는 RC1 `14-4 악보 분석 실습`의 적용화음 문맥이다. C장조에서 D7–G–C 진행을 기본적으로 `V7/V`로 판정하되, 더 넓은 구절에서 성부와 박절이 뒷받침되면 반음계적 프리도미넌트 해석을 대안으로 선언할 수 있다.

## 결정

- 정답은 문자열 하나가 아니라 `accepted` 해석 목록으로 저장한다.
- 각 해석은 로마숫자, 기능, 종지·문맥, 해설을 가진다.
- 선언된 해석 중 하나와 제출 필드가 모두 맞으면 정답이다.
- 일부 필드만 맞으면 학습용 진단 점수를 보여주되 단원 완료 정답으로 처리하지 않는다.
- 선언되지 않은 해석을 AI가 임의로 정답에 추가하지 않는다.
- 자동 판정은 기호와 명시된 문맥만 담당한다. 성부, 박절, 구절 경계, 역사적 관행의 평가는 전문가 해설 영역이다.

## 규칙 기반 Validator의 한계

동일한 화음도 앞뒤 진행, 지속음, 전위, 박절, 분석 수준에 따라 기능이 달라질 수 있다. 따라서 Validator는 “유일한 음악적 진실”을 계산하지 않고 저자가 검수한 허용 해석과 응답을 비교한다.

## MVP 이후

- 실제 악보 구간 선택과 성부별 근거 표시
- 조성 후보 자동 추정
- 자유 서술 분석의 의미 비교
- 전문가 공동 검수와 해석 버전 이력
- AI가 제안한 새 해석의 승인 워크플로
