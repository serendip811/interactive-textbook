# RC1 체크포인트 56문항 이전 방식

## 결정

RC1의 PART 3~16 체크포인트 56문항은 삭제하거나 새 문제로 간주하지 않고 원문 질문·선택지·정답·해설을 그대로 보존한다.

현재 스키마에는 PART 단위 평가 영역이 없으므로 각 문제를 가장 직접적으로 관련된 단원의 `assessment.multiple-choice` Block으로 연결한다. 단원의 완료 조건에도 해당 Block을 포함해 단순 참고 문제가 아니라 실제 학습 완료 조건으로 사용한다.

## 분배 원칙

- 음계·조표·관계조 문제는 해당 개념 단원에 직접 연결
- 화음 종류·전위·해결 문제는 해당 화음 단원에 연결
- 기능·종지·진행 문제는 동일한 기능 또는 종지 단원에 연결
- 비화성음·적용화음·전조 문제는 용어와 해결 문맥이 같은 단원에 연결
- 분석·성부진행·양식 문제는 해당 고급 단원에 연결
- 한 단원에 두 문제가 필요한 경우 Block을 둘 다 추가

정확한 56개 연결은 생성 파일 `books/harmony/src/legacy-checkpoints.generated.ts`의 `targetLessonId`가 단일 기준이다. 이 파일은 `migration/harmony-rc1-checkpoints.json`과 `scripts/generate-harmony-checkpoint-blocks.mjs`에서 재생성한다.

## 함께 수정한 내용 오류

`10-4 선행음`은 RC1에서 “다음 화음의 음을 미리 들려주는 비화성음”, 즉 anticipation 의미로 사용한다. 1차 이전본은 이를 appoggiatura의 도약 진입·순차 해결로 잘못 설명했다. RC1의 정의와 체크포인트 문항에 맞춰 다음 화음음의 선취와 계류음과의 시간 방향 비교로 수정했다.

## 자동 검사

- 체크포인트 Block 수가 정확히 56개인지 검사
- 모든 Block이 원문 해설을 포함하는지 검사
- 정답이 선택지 안에 존재하는지 검사
- 대상 단원의 완료 조건이 새 Block을 포함하는지 검사
- 전체 Book의 ID·참조·지원 Block 검사를 다시 수행
