# 화성학 76개 단원 이전 계획

## 원칙

- RC1은 비교 기준으로 보존하고 새 플레이어에 파트 단위로 이전한다.
- 제목·본문·문제의 기계 추출과 화성학적 판단을 분리한다.
- 각 단원은 `추출 → 스키마 변환 → 자동 검사 → 내용 검수 → 상호작용 검수 → RC1 비교`를 통과해야 완료된다.
- 같은 의미 데이터에서 악보·건반·오디오·판정이 파생되는지 가장 먼저 확인한다.

## 이전 그룹

| 그룹 | PART | 단원 수 | 특징 | 처리 방식 |
|---|---|---:|---|---|
| 단순 | 0–3 | 17 | 개념 설명, Pitch, 음정, 음계 중심 | 본문 자동 추출 후 공통 View 조합 |
| 조합 | 4–13 | 44 | Chord, Progression, 기능, 비화성음, 전조 | 의미 데이터 수동 검수와 Activity 연결 |
| 고급 | 14–16 | 15 | 분석, 성부진행, 양식·종합 문제 | 복수 해석·전문가 검수 중심 |

## 파트 이전 순서

학습 순서와 기존 도구 재사용성을 함께 고려한다.

1. PART 0–2: 기초, 음, 음정
2. PART 4–5: 3화음과 7화음
3. PART 3: 조성과 조표
4. PART 6–9: 다이어토닉 코드, 기능, 종지, 진행
5. PART 10–13: 비화성음, 적용화음, 반음계 화성, 전조
6. PART 15: 성부진행
7. PART 14: 종합 화성 분석
8. PART 16: 시대·양식별 종합 연습

## 자동 추출 범위

- 단원 ID, 제목, 파트, 본문 문단과 목록
- `data-sequence` 음 문자열과 재생 시간
- 객관식 선택지, 정답 키, 기존 해설
- 악보·건반·듣기 버튼 존재 여부
- 반복되는 설명·문제 문구와 RC1 원본 위치

자동 추출 결과는 초안이며 곧바로 공개하지 않는다.

## 사람 검수 범위

- 음정 이름, 화음 구성음, 조표, 로마숫자, 기능과 종지 판정
- 이명동음 표기와 성부별 옥타브
- 악보·건반·오디오의 실제 일치
- 복수 해석이 가능한 화성 분석과 전조 문맥
- 조작이 목표에 기여하는지, 설명만으로 충분한지에 대한 판단
- 모바일·키보드·스크린리더 사용성

## 배포 단위

| 배치 | 범위 | 공개 조건 |
|---|---|---|
| A | PART 0–2 | 기초 데이터와 음정 회귀검사 통과 |
| B | PART 3–5 | 조성·화음 정확성 검사 통과 |
| C | PART 6–9 | 진행 재생과 종지 판정 동기화 통과 |
| D | PART 10–13 | 반음계 표기와 전조 문맥 검수 통과 |
| E | PART 14–16 | 복수 해석·성부진행·종합 검수 통과 |

배치는 기존 공개 교재를 덮어쓰지 않고 기능 플래그 또는 콘텐츠 버전으로 교체한다. 각 배치 실패 시 마지막 통과 버전을 유지한다.
