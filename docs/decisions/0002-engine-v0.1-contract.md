# ADR 0002: Engine v0.1 최소 계약

- 상태: 승인
- 날짜: 2026-08-23

## 결정

교재 본문은 `Book → Part → Lesson → Block` 데이터로 표현한다. 공통 엔진은 과목 의미 타입을 직접 참조하지 않고, 과목 도구를 `subject + kind` 키로 등록한다. 음악의 `Pitch`, `Interval`, `Chord`, `Progression`은 `subjects/music`에 둔다.

플레이어는 등록된 블록을 순서대로 렌더링하고 지원하지 않는 블록은 안전한 오류 화면으로 대체한다. 재생은 한 번에 하나의 세션만 활성화하며 새 세션이 이전 세션의 `AbortSignal`을 중단한다.

## 결과

- HTML에 본문을 직접 넣지 않고 교재 데이터를 교체할 수 있다.
- 공통 블록과 과목별 Activity의 경계가 분명하다.
- 두 번째 과목을 추가해도 공통 엔진을 음악 중심으로 바꾸지 않는다.
- Phase 2부터 실제 단원을 이전하며 계약을 검증한다.
