# 함수와 그래프 파일럿 사용성 테스트

> 상태: 사전 기술 점검 완료, 실제 학습자 관찰 대기  
> 대상 URL: `https://serendip811.github.io/interactive-textbook/?book=functions`

## 대상

- 중학교 1~2학년 또는 함수를 처음 다시 배우는 성인 5명 이상
- 정수 사칙연산은 가능하지만 기울기·절편·교점을 아직 배우지 않았거나 자신 없는 학습자
- 모바일 3명 이상, 데스크톱 2명 이상

## 진행 원칙

진행자는 정답이나 조작 순서를 설명하지 않는다. 막힌 시점, 처음 시도한 조작, 오답 뒤 행동, 학습자가 말한 이유를 기록한다.

## 과제

1. 함수와 그래프 교재를 열고 첫 단원에서 점 `(2, 3)`을 배치한다.
2. `y = 2x + 1`에서 출력 7을 만드는 입력을 찾는다.
3. 기울기 2인 직선을 만든다.
4. 기울기를 유지하면서 y절편이 -2인 직선을 만든다.
5. `y = x`와 `y = -x + 2`의 교점을 찾는다.
6. 새로고침한 뒤 완료 표시가 남는지 확인한다.
7. 화성학으로 이동했다가 함수와 그래프로 돌아온다.

## 관찰 질문

| 검증 항목 | 성공 기준 |
|---|---|
| 계수 조작 목적 | 별도 설명 없이 목표 수식과 조절할 값을 연결한다. |
| 수식·표·그래프 연결 | 셋 중 둘 이상을 근거로 답을 설명한다. |
| 학습 목표 기여 | 조작 뒤 기울기·절편·교점의 의미를 자기 말로 설명한다. |
| 오답 피드백 | 피드백을 읽고 다음 시도에서 바꿀 값을 고른다. |
| 진도와 교재 전환 | 새로고침·교재 전환 후 현재 교재의 진도를 찾는다. |

## 사전 기술 점검 결과 — 2026-08-24

- 공개 배포에서 다섯 Activity를 키보드만으로 완료했다.
- 다섯 단원의 완료 표시가 새로고침 뒤 모두 복원됐다.
- 수식·표·그래프가 계수 조작과 함께 갱신됐다.
- 오답 피드백은 현재 좌표 또는 현재 출력과 목표를 함께 제시했다.
- 애플리케이션 자체 콘솔 오류는 발견되지 않았다. 테스트 브라우저 확장 프로그램의 메타데이터 전송 오류는 제품 코드와 무관했다.

## 이슈 분류 기준

- 공통: 단원 이동, 포커스, 진도 저장, 공통 Block, 공통 레이아웃
- 수학: 좌표축, 수식 표기, 표·그래프 동기화, 수학 피드백
- 음악: 악보, 건반, 오디오, 음악 Validator

실제 학습자 관찰이 필요한 네 항목은 결과를 추정하지 않고 테스트 후 기록한다.
