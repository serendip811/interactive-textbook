# Harmony 76개 단원 품질 감사 — 자동화 1차

## 목적

전체 이전 직후 사람이 화면을 전수 검수하기 전에 기계적으로 확인할 수 있는 대응 관계와 평가 자산을 고정한다.

## 이번에 추가한 검사

- RC1의 76개 단원 번호·제목과 새 교재의 번호·제목 완전 일치
- 모든 단원에 학습목표, Subject Activity, 요약, 명시적 완료 조건 존재
- 모든 Block의 학습목표 참조가 실제 목표 ID를 가리키는지 확인
- 모든 객관식 정답 ID가 실제 선택지에 포함되는지 확인
- RC1 PART 3~16의 체크포인트 14개, 56문항 보존
- 체크포인트마다 질문, 선택지 4개, 정답, 해설을 비교 가능한 JSON으로 추출

## 발견한 상태

- 단원 본문과 새 단원별 확인 문제는 76개 구조 안에 존재한다.
- RC1의 체크포인트 56문항은 지금까지 별도 비교 기준이 없었으며 이번에 `migration/harmony-rc1-checkpoints.json`으로 처음 고정했다.
- 후속 작업에서 56문항을 관련 단원의 평가 Block과 완료 조건에 모두 연결했다. 정확한 연결은 `docs/migrations/harmony-checkpoint-mapping.md`에 기록한다.

## 다음 검수 순서

1. [완료] PART 0~5의 악보·건반·오디오 표적 비교
2. PART 6~13의 기능·전조 전문 내용 검수
3. PART 14~16의 복수 해석·성부진행 전문가 검수
4. 모바일 390px 및 실제 iPhone 상호작용 검수

PART 0~5 결과는 `docs/testing/harmony-part0-5-media-review-2026-08-24.md`에 기록했다.

이 문서는 자동화 가능한 검수만 다루며 `내용 검수` 또는 `상호작용 검수` 완료를 의미하지 않는다.
