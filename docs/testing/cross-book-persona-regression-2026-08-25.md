# 화성학·함수 교재 10개 페르소나 조작 회귀 검수

> 실행일: 2026-08-25
>
> 대상: 공개 배포된 화성학 76단원과 함수와 그래프 5단원
>
> 방식: 브라우저 조작 기반 에이전트 페르소나 대리 점검

실행 환경의 동시 에이전트 한도는 루트 포함 4개였으므로, 3개 하위 에이전트 스레드가 페르소나를 교대해 총 10개의 독립된 관점과 과업으로 순차 검수했다. 이 결과는 UI 동작과 데이터 일관성을 찾는 휴리스틱 검수이며 실제 사람의 망설임, 청각 경험, 운동·시각 조건을 대신하지 않는다.

클라우드 브라우저의 뷰포트는 `1363×936`, DPR 1로 고정됐다. 따라서 실제 iPhone 폭의 목차 드로어, 수평 건반 스크롤, 한 손 터치와 iOS 오디오 정책은 DOM·CSS 근거만 확인했으며 실기기 확인 대상으로 남긴다.

## 통과한 회귀 항목

- 화성학 76단원과 함수 5단원이 공개 목차와 원본에서 일치한다.
- 최초 단원 로드, 객관식 선택·채점·오답 회복, 완료 체크가 정상이다.
- 다음·이전 단원 이동 후 `scrollY=0`이고 새 H1으로 포커스가 이동한다.
- skip link, 공통 포커스 표시, 직접 조작형 건반의 roving tabindex·방향키·Enter·Space가 정상이다.
- 화음 탭을 빠르게 전환해도 악보·건반·`aria-pressed`가 마지막 의미 데이터와 일치한다.
- 답을 여러 번 바꾸고 재채점해도 마지막 선택과 피드백이 일치한다.
- 함수 좌표 `(2,3)`, 함수 머신 `(3,7)`, 기울기·절편, 교점 `(1,1)`의 오답 회복과 채점이 정상이다.
- 함수 `y=2x+1`의 출력 7이 확장된 그래프 범위 안에 표시된다.
- 화성학과 함수 교재를 빠르게 전환해도 빈 화면이나 혼합 콘텐츠가 나타나지 않는다.
- 화성학과 함수의 현재 단원·완료 기록은 서로 분리해 복원되며 `새 학습 시작`은 현재 교재 기록만 초기화한다.
- 화성학 마지막 단원은 `76/76` 완료와 비활성화된 다음 단원 버튼을 유지한다.
- 앱 자체 콘솔 오류는 재현되지 않았다.

## 판정과 다음 순서

현재 판정은 `수정 필요`다. 화면 조작의 치명적 회귀나 크래시는 없었지만, AGT-024는 수업이 가르치는 규칙을 예시가 위반하고 AGT-025는 청취 평가의 오디오를 훼손할 수 있어 먼저 수정해야 한다.

1. AGT-024와 AGT-025를 각각 독립 커밋으로 수정한다.
2. AGT-034의 의미 회귀 테스트를 추가한다.
3. AGT-026~033을 접근성·학습 의미 순서로 수정한다.
4. 자동 브라우저로 표적 재검증한다.
5. iPhone 390px급 실기기에서 모바일 목차, 긴 건반 수평 스크롤, 한 손 터치, 실제 오디오를 확인한다.
6. 실제 참여자 최소 5명의 사용성 테스트는 에이전트 결과와 분리해 수행한다.
