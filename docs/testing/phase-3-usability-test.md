## 참여자

- 목표: 최소 5명
- 음악 이론 초보 3명 이상, 기초 경험자 1~2명
- 모바일 사용자를 최소 3명 포함
- 같은 가구나 같은 직군에만 편중되지 않게 모집
- 테스트 전 이름 대신 `P1`~`P5` 식별자만 부여

## 진행 원칙

- 한 명씩 20~25분 진행한다.
- 화면과 손의 움직임을 관찰하되, 막히기 전에는 사용법을 알려주지 않는다.
- 10초 이상 망설이면 관찰 메모에 기록한다.
- 30초 이상 막히면 “지금 무엇을 하려고 했나요?”만 질문한다.
- 60초 이상 진행하지 못하면 최소한의 힌트를 주고 힌트 사용 여부를 기록한다.
- 계정, 연락처, 얼굴 영상 등 개인정보는 저장하지 않는다.

## 관찰 시나리오

설명 없이 공개 교재를 열어 다음을 수행하도록 요청한다.

1. 반음과 온음에서 두 음을 선택하고 정답을 확인한다.
2. C4에서 완전5도를 만든다.
3. C장3화음의 구성음을 고른다.
4. 종지를 전체로 들은 뒤 한 단계씩 다시 듣고 유형을 고른다.
5. 병행8도가 사라지도록 소프라노 도착음을 바꾼다.

각 과제는 `도움 없이 성공`, `망설인 뒤 성공`, `힌트 후 성공`, `실패` 중 하나로 기록한다.

## 질문

- 다음에 무엇을 눌러야 하는지 안내 없이 알 수 있었는가?
- 악보와 건반이 함께 변하는 것이 이해에 도움이 되었는가?
- 전체 듣기와 단계 듣기의 차이를 알 수 있었는가?
- 오답 메시지를 읽고 스스로 수정할 수 있었는가?
- RC1과 새 버전 중 어느 쪽을 선호하며 그 이유는 무엇인가?

질문은 과제를 모두 마친 뒤 한다. 진행 중에는 참가자의 행동과 혼잣말을 우선 관찰한다.

## Phase 3 판정 기준

- 5명 중 4명 이상이 핵심 과제 5개 중 4개 이상을 힌트 없이 완료한다.
- 5명 중 4명 이상이 악보와 건반의 연결이 이해에 도움이 된다고 답한다.
- 5명 중 4명 이상이 전체 듣기와 단계 듣기의 차이를 설명한다.
- 오답을 경험한 참여자의 80% 이상이 피드백만 읽고 다음 시도에서 수정한다.
- `차단` 문제는 0건이어야 한다.
- 학습 결과를 왜곡하는 `중요` 문제는 모두 수정하거나 재검증 계획을 기록한다.
- 신규 버전 선호가 RC1보다 낮으면 이유를 분석하고 Phase 3 통과를 보류한다.

## 종료 절차

1. 세션별 기록지를 완성한다.
2. 결과 취합표에 성공 여부와 관찰 사항을 옮긴다.
3. 같은 원인의 문제를 하나로 묶는다.
4. 심각도와 발생 인원수를 기준으로 수정 순서를 정한다.
5. 수정 후 해당 과제만 1~2명에게 다시 확인한다.
6. 판정 기준을 만족하면 TODO의 Phase 3 통과 조건을 체크한다.
