# Harmony 1-2 Phase 2 비교 검수

## RC1과 동일하게 유지한 것

- 정의: 반음은 가장 작은 기본 거리이고 온음은 반음 두 개다.
- 자연음 예제: E4–F4, B4–C5
- 악보, 건반, 순차 오디오 표현
- 핵심 요약 세 문장

## 개선한 것

- 악보·건반·오디오가 별도 문자열 대신 같은 `Pitch[]`를 사용한다.
- 관찰형 안내를 두 음을 직접 선택하는 활동으로 바꿨다.
- 실제 반음 수와 반음·온음 판정을 즉시 알려준다.
- 선택 순서, 재생 음과 정오 상태를 색상뿐 아니라 숫자와 텍스트로 표시한다.
- 키보드 포커스, 44px 이상 조작 버튼, 작은 화면 전용 건반 높이를 적용했다.
- Activity 응답·정오·시도 횟수·완료 상태를 콘텐츠 버전과 함께 저장한다.

## 더 복잡해진 지점

- 오디오 세션과 로컬 상태의 생명주기를 관리해야 한다.
- 흰 건반의 흐름과 검은 건반의 절대 위치를 별도로 계산한다.
- 콘텐츠 버전 변경 시 이전 학습 기록을 초기화한다.

## 자동 비교

`tests/regression/harmony-semitone.test.ts`가 RC1 예제의 음 이름과 반음 수, 목표 연결 및 완료 조건을 고정한다. 기존 RC1 정적 회귀검사 11개도 함께 실행한다.
