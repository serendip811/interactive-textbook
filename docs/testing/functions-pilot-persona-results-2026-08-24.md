# 함수와 그래프 10개 페르소나 사용성 재검증

> 날짜: 2026-08-24
> 대상: 공개 GitHub Pages 함수와 그래프 5개 단원
> 방식: 브라우저 조작 기반 에이전트 페르소나 대리 점검

## 범위와 한계

추가 에이전트 스레드 생성이 실행 환경에서 차단되어, 계획한 독립 에이전트 10명 대신 한 에이전트가 페르소나별 과업과 입력 방식을 분리해 순차 수행했다. 실제 학습자의 이해도·감정·설명 능력을 관찰한 결과가 아니라 UI 행동 경로와 발견 가능성을 검토한 휴리스틱 대리 테스트다.

| # | 페르소나 | 중점 경로 | 결과 | 관찰 |
|---:|---|---|---|---|

## 실제 브라우저 재현 결과

- 함수 입력 오답: `현재 출력은 1입니다. 목표 출력 7과 비교하세요.`
- 함수 입력 정답: 그래프/방향키로 `(3, 7)` 선택 후 완료
- 좌표 오답: `(3, 3)`에서 y좌표가 맞고 x좌표를 고치라고 안내
- 기울기 오답: y절편은 맞고 기울기를 조정하라고 안내
- 절편 오답: 기울기는 맞고 y절편을 조정하라고 안내
- 교점 오답: `(1, 0)`에서 x좌표가 맞고 y좌표를 고치라고 안내
- 새로고침·교재 전환 후 다섯 완료 상태 복원

## 발견 및 처리

| 우선순위 | 분류 | 문제 | 처리 |
|---|---|---|---|
| 보통 | 수학 View | 그래프의 현재 점과 입력·출력 표의 어느 열이 연결되는지 약함 | 선택된 x/y 열을 색상·테두리로 강조하고 caption에 선택 열 추가 |
| 보통 | 수학 피드백 | `기울기을 다시 조정하세요` 조사 오류 | `기울기를 다시 조정하세요`로 수정, 단위 테스트 추가 |
| 보통 | 접근성 | 함수 그래프에서 위·아래 방향키가 결과를 바꾸지 않지만 일반 방향키 안내를 제공 | 좌우 방향키 안내 및 좌우키만 처리하도록 수정 |
| 낮음 | 콘텐츠 | 목표식을 그대로 보여주는 직선 만들기는 탐색보다 값 맞추기에 치우칠 수 있음 | 실제 학습자 테스트에서 난이도 관찰 후 다중 과제로 확장 검토 |

높은 우선순위 결함은 발견되지 않았다.
