# Phase 3 에이전트 페르소나 사용성 사전 점검

> 실행일: 2026-08-24
>
> 대상: 공개 배포된 화성학 대표 5개 단원
>
> 성격: 실제 참여자 테스트 전의 시뮬레이션 기반 휴리스틱 점검

이 결과는 서로 다른 조건을 부여한 에이전트가 각자 독립된 브라우저 탭에서 보이는 UI만 조작해 얻었다. 실제 사람의 망설임, 운동 능력, 청각적 이해와 감정 반응을 대신할 수 없으므로 Phase 3의 `최소 5명 테스트` 통과 근거로 사용하지 않는다.

## 페르소나

| ID | 조건 | 수행 환경 |
|---|---|---|
| P1 | 음악 이론 무경험, 앱 사용에 익숙함 | 브라우저, 포인터 |
| P2 | 피아노 1년, 화성학 용어 미숙 | 브라우저, 포인터 |
| P3 | 50대, 음악 이론 무경험, 웹 조작 자신감 낮음 | 브라우저, 포인터 |
| P4 | 음악 경험자, 표기와 데이터 정확성에 민감 | 브라우저, 포인터 |
| P5 | 음악 기초 경험, 마우스를 쓰지 않는 키보드 전용 사용자 | 브라우저, 키보드 |

## 공통 강점

- 정답·오답 피드백은 대체로 구체적이며 다음 시도를 돕는다.
- 건반의 선택 순서 배지와 `aria-pressed` 선택 상태는 음의 관계를 추적하는 데 유용하다.
- 대표 5개 단원의 의미 데이터, 건반 선택, 악보 대체 텍스트는 대체로 동기화돼 있다.
- 목차의 현재 위치와 완료 체크는 긴 학습 흐름에서 안정감을 준다.
- 전체 진행과 단계 진행의 상태 표시 자체는 재생이 시작된 뒤에는 이해하기 쉽다.
- 모든 핵심 조작을 키보드만으로 완료할 수 있고 건반의 포커스 표시는 매우 선명하다.

## 사전 판정

현재 결과는 `보류`다. 대표 활동은 포인터와 키보드로 모두 작동하지만, 비교용 RC1 404 한 건과 학습 결과·접근성을 왜곡할 수 있는 중요 문제 여섯 건이 발견됐다. 먼저 AGT-001~007을 수정하고, 에이전트 재검증 후 실제 학습자 최소 5명에게 동일 시나리오를 수행해야 Phase 3 통과 여부를 판정할 수 있다.
