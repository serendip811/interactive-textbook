## 모바일 판정

- 실행 기기 화면은 1179×2556px이며, 3배 배율 기준 논리 너비는 약 393px이다.
- `4-2`의 건반은 가로 스크롤 구조 안에서 C4 중심과 검은 건반 위치가 정상적으로 보인다.
- `2-4`는 공통 `step-play` 대신 단원 전용 개별 듣기와 `복음정 비교 듣기` 활동을 제공한다. 따라서 RC1-001은 무반응 기능이 아니라 공통 단계 버튼의 예외 설계로 기록한다.
- 자유 건반 서랍은 배경을 차단하고 제목, C4 이동, 닫기 버튼과 건반을 사용할 수 있는 높이로 열린다.
- 핵심 버튼이나 콘텐츠가 화면 밖으로 고정되어 접근 불가능한 P0/P1 모바일 오류는 캡처에서 발견되지 않았다.

## 해석 주의

- 긴 단일 페이지에서 목차로 이동한 직후 캡처하면 이전·다음 단원의 하단이 함께 보일 수 있다.
- 화면에 보인 문구가 의심스러울 때는 해당 단원의 HTML 원문과 함께 대조한다.
- 이번 대조 결과 `14-4`와 `15-2`의 본문 데이터 자체에는 캡처만으로 확정할 새 오류가 없었다.
