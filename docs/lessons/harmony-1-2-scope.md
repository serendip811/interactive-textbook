# Phase 2 단원 범위: 1-2 반음과 온음

## 목표

학습자는 건반에서 두 음을 선택하고 두 음 사이의 반음 수를 확인하여 반음과 온음을 구별할 수 있다.

## 선수 지식

- C부터 B까지의 음 이름
- 건반에서 오른쪽으로 갈수록 음이 높아진다는 사실

## 학습 흐름

1. 반음과 온음의 정의
2. E–F, B–C 예제를 같은 Pitch 데이터로 악보·건반·오디오에 표시
3. 건반에서 두 음을 직접 선택해 거리 판정
4. 객관식 확인 문제와 즉시 피드백
5. 핵심 요약

## 완료 조건

`반음·온음 탐색기`에서 한 문제를 맞히고 확인 문제를 제출하면 완료한다. Activity 응답, 정오 여부와 시도 횟수는 로컬에 저장한다.

## RC1에서의 변경

- 핵심 정의와 E–F, B–C 예제는 보존한다.
- 모든 단원에 반복된 세 개의 서술형 문항은 제거한다.
- “직접 확인” 안내를 실제 건반 선택 Activity로 바꾼다.
- C–C♯, C–D 예제를 추가해 임시표가 포함된 반음도 확인한다.
