# 함수와 그래프 미니 교재 파일럿 범위

> 상태: Phase 4.1 확정
>
> 목적: 화성학과 다른 과목에서도 하나의 의미 데이터가 수식·표·그래프·조작·판정을 함께 만드는지 검증한다.

## 대상 학습자와 선수 지식

- 대상: 중학교 1~2학년 또는 함수를 처음 다시 배우는 성인
- 예상 학습 시간: 단원당 8~12분, 전체 50~60분
- 필요한 선수 지식: 정수의 사칙연산, 간단한 일차식, 수직선의 양수·음수
- 별도 선수 지식으로 요구하지 않는 것: 좌표 읽기, 함수 용어, 기울기, 절편, 연립방정식

교재는 공식을 먼저 암기시키지 않는다. 학습자가 값을 바꾸고 결과를 관찰한 뒤 수식과 용어를 연결하도록 구성한다.

## 공통 학습 흐름

각 단원은 다음 순서를 기본으로 한다.

1. 짧은 개념 설명
2. 동일한 의미 데이터로 수식·표·그래프 표시
3. 값을 직접 조작하고 세 표현의 변화 관찰
4. 목표 상태 만들기 또는 위치 선택
5. 구체적인 즉시 피드백
6. 핵심 정리와 완료 상태 저장

## 단원 명세

### 1. 좌표와 점

학습 목표:

- x좌표와 y좌표의 순서를 구별한다.
- 주어진 좌표 `(x, y)`를 좌표평면의 점과 연결한다.
- 좌표평면에서 선택한 점의 좌표를 읽는다.

핵심 조작:

- 좌표평면에 목표 점 배치
- 점을 움직일 때 좌표 표기가 함께 갱신

완료 조건:

- 서로 다른 사분면의 목표점 3개 중 2개 이상을 오차 없이 배치한다.

### 2. 함수의 입력과 출력

학습 목표:

- 하나의 입력값에 하나의 출력값이 대응한다는 뜻을 설명한다.
- 함수 규칙에 입력값을 넣어 출력값을 구한다.
- 같은 함수 데이터에서 수식·입출력 표·그래프 점이 연결됨을 확인한다.

핵심 조작:

- 입력값 슬라이더 또는 숫자 선택
- 입력 변화에 따른 출력·표의 행·그래프 점 동시 강조

완료 조건:

- 주어진 함수에서 목표 출력값을 만드는 입력값 2개를 연속으로 찾는다.

### 3. 일차함수의 기울기

학습 목표:

- `y = ax + b`에서 `a`가 기울기임을 안다.
- 기울기의 부호가 직선의 증가·감소 방향을 결정함을 확인한다.
- 기울기의 절댓값이 커질수록 직선이 더 가파르게 변함을 비교한다.

핵심 조작:

- 기울기 `a` 슬라이더
- 수식·값의 표·직선 그래프 동시 갱신

완료 조건:

- 목표 방향과 가파르기에 맞는 기울기를 두 번 연속 선택한다.

### 4. 절편의 변화

학습 목표:

- `y = ax + b`에서 `b`가 y절편임을 안다.
- 기울기를 유지한 채 절편만 바꾸면 직선이 평행 이동함을 확인한다.
- 그래프에서 y절편을 읽고 수식의 `b`와 연결한다.

핵심 조작:

- 절편 `b` 슬라이더
- 이전 직선과 현재 직선을 함께 표시해 평행 이동 비교

완료 조건:

- 기울기를 바꾸지 않고 지정된 y절편을 지나는 직선을 만든다.

### 5. 두 직선의 교점

학습 목표:

- 교점이 두 함수식을 동시에 만족하는 점임을 이해한다.
- 두 그래프에서 교점의 좌표를 읽는다.
- 교점 좌표를 두 식에 대입해 같은 출력값이 됨을 확인한다.

핵심 조작:

- 두 직선 중 하나의 기울기 또는 절편 변경
- 그래프 교점·좌표·두 식의 대입 결과 동시 갱신

완료 조건:

- 목표 교점을 만들거나 제시된 두 직선의 교점을 정확히 선택한다.

## 파일럿 성공 기준

- 다섯 단원이 화성학과 같은 플레이어·공통 블록·학습 상태를 사용한다.
- `LinearFunction` 하나에서 수식, 표, 그래프와 판정 결과가 파생된다.
- 수학 도구 등록을 위해 음악 코드가 수정되지 않는다.
- 최소 세 가지 수학 조작 Activity가 완성된다: 점 배치, 목표 직선 만들기, 교점 찾기.
- 각 단원의 오답 피드백이 현재값과 목표의 차이를 구체적으로 설명한다.

## 파일럿 제외 범위

- 이차함수와 곡선
- 연립방정식의 대수적 풀이 절차
- 자유 서술형 증명
- 단위·물리량이 포함된 응용 문제
- 교사용 문항 제작기와 AI 자동 생성

이 항목들은 엔진의 수학 확장 가능성을 확인한 뒤 별도 범위로 검토한다.
