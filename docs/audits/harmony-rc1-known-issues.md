## 0.4 항목별 목록

### 화성학 내용 오류

- 현재 정적 검사로 확정된 화성학 내용 오류는 없다.
- PART 10~16의 비화성음·차용화음·전조·화성 분석은 전문 검수 대기다.
- 단일 정답으로 제시된 분석 문제는 대안 해석 가능성을 검토한다.
- P0 내용 오류가 발견되면 Engine 작업보다 먼저 RC1을 수정한다.

### 플랫과 샵 표기

- 최신 RC1은 `Fs`, `Cs`, `Eb`, `Bb`, `Ab`, `Db` 등 의미 표기를 `data-sequence`에 보존한다.
- 건반 하이라이트에서는 플랫을 이명동음 샵 키로 변환하고 별도 라벨로 원래 표기를 표시한다.
- 정적 JSON 파싱 오류는 0개다.
- 검수 대상: C♯/D♭처럼 같은 건반이지만 의미가 다른 예제가 악보·라벨·오디오에서 동일하게 유지되는지 확인한다.

### 반음 수 계산

- `noteMidi()`의 피치클래스 매핑과 최저·최고 MIDI 차이로 계산한다.
- 정적 코드상 알려진 계산식 오류는 없다.
- 기존 수정 이력에 반음 수 표시 오류가 있었으므로 경계값 0·1·2·6·12·15와 하행 음정을 회귀 검사한다.
- 음정의 도수와 반음 수가 서로 다른 개념임을 피드백에서 혼동하지 않는지 확인한다.

### 악보와 건반 불일치

- 두 표현 모두 같은 `data-sequence` 문자열을 사용한다.
- 정적 데이터 누락이나 JSON 오류는 발견되지 않았다.
- VexFlow는 원래 플랫·샵을 렌더링하고 건반은 이명동음 위치에 원래 표기 라벨을 붙이므로 실제 화면 비교가 필요하다.
- 대표 검사: `1-3`, `2-3`, `2-4`, `12-2`, `12-3`, `13-5`.

### 악보와 오디오 불일치

- 악보와 듣기 버튼은 대부분 동일한 `data-sequence`를 중복 보유한다.
- DOM상 동일해 보여도 서로 독립된 속성이므로 한쪽만 수정될 수 있는 구조적 위험이 있다.
- 대표 단원에서 악보 음표, 버튼 데이터, 실제 들리는 음의 MIDI 값을 비교한다.

### 전체 듣기와 건반 하이라이트 불일치

- 최신 capture-phase 재생기가 820ms 간격으로 건반 상태와 오디오를 함께 진행한다.
- 이전 클릭 리스너도 남아 있어 버튼 위치에 따라 처리 경로가 달라진다.
- 전체 재생 중 다른 버튼 클릭, 빠른 연속 클릭, 긴 진행의 마지막 단계와 초기화 상태를 확인한다.

### 검은 건반 위치

- 최신 RC1은 흰 건반 너비를 기준으로 검은 건반 `left` 위치를 동적으로 계산한다.
- 데스크톱은 흰 건반 54px/검은 건반 34px, 모바일은 50px/32px을 사용한다.
- 기존 고정 위치 문제는 해결된 상태로 보이나 900px 경계와 화면 회전은 회귀 검사 대상이다.

### 작동하지 않는 버튼

- 정적으로 확정된 무반응 버튼은 없다.
- `2-4 복음정`에는 공통 한 단계씩 듣기 버튼이 없지만 개별 음정 듣기와 `복음정 비교 듣기` 활동은 모바일 Safari에서 확인됐다.
- 오디오는 사용자 제스처 이후 활성화되므로 첫 클릭, Safari/iOS, 백그라운드 복귀 후 재생을 확인한다.
- 체크포인트는 답변 후 버튼을 비활성화하며 재시도·초기화 버튼이 없다.

### 모바일 화면

- 건반은 가로 스크롤과 현재 음 자동 중앙 정렬을 사용한다.
- 검은 건반 동적 배치가 최신 RC1에 반영됐다.
- 320px, 375px, 768px, 900px 전후와 가로 회전에서 목차·건반·악보·자유 건반 서랍을 확인한다.
- 긴 VexFlow SVG와 진행 라벨의 잘림 여부는 브라우저 검수 대기다.

### 반복 설명과 반복 문제

- “직접 악보나 건반으로 확인해 보세요”가 70회 반복된다.
- “핵심 개념을 한 문장으로 설명하시오”가 71회 반복된다.
- 대표 예시 변형 문제와 앞 단원 연결 문제도 각각 71회 반복된다.
- 화성학 v2 이전 시 목표·오개념·판정 기준이 다른 문제로 교체한다.

### 관찰형 활동

- 대부분의 단원은 사용자가 음이나 화음을 구성하는 대신 예시를 듣고 읽는 방식이다.
- Engine v0.1에서는 `1-2`, `2-3`, `4-2`, `8-5`, `15-2`를 실제 입력과 즉시 판정이 있는 Activity로 바꾼다.
- 공통화는 서로 다른 두 단원에서 반복된 뒤에만 수행한다.

### 접근성

- 기본 버튼 요소와 일부 `aria-label`, 자유 건반의 `aria-live`, Escape 닫기는 구현되어 있다.
- 자유 건반 서랍의 포커스 이동·가두기·복귀가 없다.
- 재생 단계와 채점 결과의 상태 변경이 일관되게 라이브 영역에 전달되지 않는다.
- `prefers-reduced-motion` 대응이 없다.
- 악보 SVG의 스크린리더 역할과 텍스트 대체 설명을 확인해야 한다.
- 건반을 Tab으로 이동할 수는 있지만 컴퓨터 키보드 음 연주와 화살표 탐색은 없다.

## RC1에서 바로 고칠 조건

다음 중 하나에 해당할 때만 동결된 RC1을 수정한다.

- 화성학 내용이 명백히 틀림
- 악보·건반·오디오가 서로 다른 음을 표현함
- 핵심 듣기·채점 기능이 실제로 작동하지 않음
- 모바일에서 단원을 읽거나 핵심 버튼을 누를 수 없음
- 키보드만으로 핵심 기능에 접근할 수 없는 치명적 문제

그 외 구조 문제는 Engine v0.1 요구사항 또는 화성학 v2 콘텐츠 개선 목록으로 이동한다.
